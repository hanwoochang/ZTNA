## 🛠️ 작업 내용 및 수정 사항
1. **[Step 1] BYOD 다운로드 원천 차단 적용**
   - `auth.js`: 로그인/OTP/생체인증 시 발급되는 JWT Payload에 `allowDownload: false` (BYOD인 경우) 주입 추가.
   - `server.js` (Gateway): JWT에서 `allowDownload` 값을 추출해 타겟 서버로 `x-allow-download` HTTP 헤더 전송.
   - `target.js`: 해당 헤더 값이 `false`일 경우 `/api/documents/secret.pdf` 다운로드를 403 에러로 원천 차단.
   - `IntranetScreen.tsx`: BYOD 사용자에게는 다운로드 버튼을 자물쇠 아이콘으로 변경 및 비활성화, 상단 경고 배너 렌더링.

2. **[Step 2] 실시간 세션 차단 (Session Tearing) 및 UI 동기화**
   - `auth.js`: JWT Payload에 `deviceId` 속성 추가.
   - `server.js` (Gateway): 
     - 매 API 요청(Heartbeat)마다 DB를 조회하여 해당 기기가 관리자에 의해 차단(is_trusted=0)되었는지 검증 후 401(Revoked) 반환.
     - 기기 소유 형태(device_type)를 실시간 감지하여 `req.user.allowDownload` 권한을 오버라이드하고, 변경된 상태를 프론트엔드에 `x-allow-download-sync` 헤더로 전달.
   - `useIntranet.ts`:
     - 전역 에러 핸들러(`handleApiError`)를 개선하여 401(Revoked) 반환 시 즉시 `onForceLogout()` 실행.
     - Axios 응답 헤더를 가로채어 `allowDownload` 로컬 상태를 실시간 동기화.
     - "이유: " 중복 메시지 표기 버그 수정.
   - `IntranetScreen.tsx`:
     - 유휴 상태(Idle)에서도 5초마다 상태를 체크하는 Polling(Heartbeat) 인터벌 추가하여 백그라운드 실시간 튕김 구현.
     - `allowDownload = false` (BYOD)일 경우 하단 네비게이션 및 사이드바에서 `Schedule` 탭을 완전히 숨기도록 로직 추가.
