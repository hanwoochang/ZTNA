# 📅 ZTNA 프로젝트 작업 요약 (2026-09-12)

## 🎯 오늘의 목표: 3단 탭 UI/UX 고도화 및 출퇴근 기록 연동

오늘은 기존 단일 화면으로 구성되어 있던 앱 인터페이스를 **'3단 하단 탭(Bottom Tabs)'** 구조로 전면 개편하고, 백엔드와 연동하여 실시간 출퇴근 조회 기능을 추가하는 마일스톤(4단계)을 완벽하게 수행했습니다.

---

### 1. 🛠️ 백엔드(Target Server) API 추가
* **수정 파일:** `ztna-gateway/target.js`
* **내용:** 
  - 모바일 앱 화면에 현재 출퇴근 시간을 띄워주기 위해 `GET /api/attendance/today` 엔드포인트를 신규 개발했습니다.
  - 게이트웨이의 `/private` 라우팅 미들웨어를 통해 JWT 인증 후 자연스럽게 타겟 서버로 연결되도록 연동을 확인했습니다.

### 2. 📱 프론트엔드 비즈니스 로직(Hook) 확장
* **수정 파일:** `ztna-client/hooks/useIntranet.ts`
* **내용:** 
  - 서버에서 받아온 데이터를 저장할 `attendanceData` 상태(State) 변수를 신설했습니다.
  - 출근/퇴근 버튼 클릭 시 동작하는 로직 끝단에 `fetchTodayAttendance` 함수를 엮어, **기록 완료 직후 즉시 화면의 시간이 새로고침(Refetch)되도록 구현**했습니다.

### 3. 🎨 3단 탭(Tab) 네비게이션 UI 디자인 전면 개편
* **수정 파일:** `ztna-client/screens/IntranetScreen.tsx`
* **내용:**
  - `@react-navigation/bottom-tabs` 라이브러리를 도입하여 다음의 3개 탭으로 분리했습니다.
    - **1탭(근태 관리):** 실시간 서버 연동 출퇴근 시간 + 모바일 사원증 버튼
    - **2탭(기밀 문서 & 게시판):** 최고 기밀 PDF 다운로드 + 사내 공지사항 리스트(Mock UI)
    - **3탭(환경 설정):** 인가 기기/IP 정보 패널 + `useTheme` 기반 다크/라이트 모드 실시간 전환 버튼 + 안전 종료(로그아웃)
  - 상단 카메라 노치(Notch) 영역을 침범하지 않도록 화면 전체를 `SafeAreaView`로 감싸 UI를 폴리싱했습니다.

### 4. 🚑 트러블슈팅 및 버그 픽스 (매우 중요)
* **React Navigation 컨텍스트 충돌 (Expo SDK 56 이슈):**
  - Expo Router와 수동으로 깐 탭 네비게이션 모듈이 겹쳐 렌더링이 안 되는 현상 발생.
  - `.env`에 `EXPO_ROUTER_DISABLE_RN_NAVIGATION_CHECK=1` 환경 변수를 주입하여 오류를 1차 우회.
  - `IntranetScreen`의 `Tab.Navigator`를 `<NavigationIndependentTree>`와 전용 `<NavigationContainer>`로 덮어씌워 **네비게이션 컨텍스트를 완벽하게 독립(격리)시켜 렌더링 에러를 영구 해결**했습니다.
* **IP 주소 변경에 따른 통신 차단 해제:**
  - PC가 재부팅/재연결 되며 DHCP에 의해 할당된 IP가 변경됨(`.108` -> `.105`).
  - ZTNA 게이트웨이 보안 설정(`ztna-gateway/.env`)과 클라이언트 주소(`config.ts`)를 모두 최신 IP로 갱신하여 통신 및 CORS 차단을 해제했습니다.
* **에뮬레이터 강제 차단 해제:**
  - ZTNA의 탈옥/루팅 기기 방어 로직(`checkDeviceSecurity`)이 안드로이드 에뮬레이터를 루팅폰으로 오인해 앱 진입을 원천 차단하는 현상 발생.
  - 테스트 편의를 위해 `deviceSecurity.ts`의 차단 검사 로직을 모두 `true`(Free Pass)로 반환하도록 임시 주석 처리했습니다.
