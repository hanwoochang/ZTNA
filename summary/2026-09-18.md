# 2026-09-18 작업 요약

## 1. 관리자 대시보드 레이아웃 및 디자인 개편
- **ClouDoc 레퍼런스 스타일 적용:** 둥둥 떠다니는 거대한 카드 형태에서, 기업용으로 적합하고 깔끔한 통짜형 그리드 스타일로 개편했습니다. 
- **Tailwind CSS 캐시/JIT 멈춤 현상 우회:** 여백(`gap`, `padding`)이 안 먹히는 문제를 해결하기 위해 강제적인 인라인 CSS(`style={{}}`)를 주입하여 레이아웃을 확정 지었습니다.
- **레이아웃 스크롤 분리 및 사이드바 고정:** 전체 화면 높이를 `100vh`로 강제 고정하고 최상단 컨테이너의 스크롤을 차단(`overflow: hidden`)했습니다. 이를 통해 화면 우측 데이터 영역에만 스크롤이 생기게 했으며, 사이드바는 고정된 채 로그아웃 버튼이 무조건 왼쪽 맨 아래에 위치하도록 개선했습니다.

## 2. 가짜(Hardcoded) 데이터 제거 및 실데이터(Real Data) 연동
- **불필요한 가짜 위젯 삭제:** 백엔드 기능이 아직 없는 '시스템 헬스 체크' 창과 가짜 비율(MDM/BYOD, 정지 계정 등) 등 하드코딩된 정보를 모두 제거했습니다.
- **통계 API 연결:** '총 가입 임직원 수', '등록된 단말기 수', '금일 차단 건수' 3가지 실데이터를 `/api/admin/stats`를 통해 가져오도록 상단 요약 카드를 3구역으로 재구성했습니다.
- **실시간 접근 차단 로그 연동:** '최근 전사 접속 로그' 표를 생성하고 `/api/admin/logs`를 호출하여 실제 사용자 이메일, IP 주소, 위험도 점수, 사유, 차단 여부를 화면에 실시간으로 출력하도록 연결했습니다.

## 3. JWT 인증 만료(401) 자동 로그아웃 처리
- 토큰이 만료되었을 때 데이터가 비어 보이는 현상을 수정하기 위해, Axios 글로벌 응답 인터셉터를 추가했습니다.
- 통신 중 `401 Unauthorized` 에러가 발생하면 로컬 스토리지에서 토큰을 자동 삭제하고 즉시 `/login` 화면으로 리다이렉트 시켜 유저 혼선을 방지했습니다.

## 4. 기타 UI 튜닝
- 우측 상단의 불필요했던 검색, 알림, 설정 아이콘 그룹을 제거하여 심플한 헤더를 구성했습니다.
- 위젯 내용물이 겹치거나 선에 닿지 않도록 상자 내부 여백(`padding`)을 넉넉하게 재설정했습니다.
