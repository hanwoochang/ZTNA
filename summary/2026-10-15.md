*   **보안 그룹 (Security Group) 인바운드 규칙 구성:**

    *   포트 80 (HTTP): 관리자 웹 서비스 (Nginx)

    *   t3.micro(물리 메모리 1GB) 환경에서 패키지 빌드 및 MySQL 구동 시 발생할 수 있는 OOM(Out of Memory) 현상을 방지하기 위해 2GB Swap 공간 생성.
    *   `/etc/fstab`에 자동 마운트 등록하여 서버 재부팅 시에도 2GB 가상 메모리가 상시 유지되도록 조치.

    *   Ubuntu 24.04 / MySQL 8.4 표준에 맞추어 전용 데이터베이스 사용자 `ztna_user` 생성 및 권한 부여.
*   **PM2 프로세스 매니저 기반 백엔드 마이크로서비스 3종 무중단 가동:**

    2.  `intranet-target` (포트 5000, 127.0.0.1 로컬 바인딩): 외부에서 직접 접근할 수 없도록 격리된 가상 사내망 백엔드.
    3.  `ztna-gateway` (포트 4000): ZTNA PEP 관문 프록시, 인가된 JWT 토큰 및 보안 정책 검증 후 인트라넷 중계.
*   **서버 재부팅 대비 자동 복구 체계:**
    *   `pm2 save` 및 systemd 서비스 등록을 완료하여 서버 재부팅 시 모든 백엔드 프로세스가 자동 기동되도록 구성.

    *   Vite 프로덕션 빌드(`npm run build`) 수행 후 산출물을 `/var/www/html`에 배포.
*   **SPA(Single Page Application) 라우팅 지원:**

*   **관리자 로그인 및 대시보드 검증:**
