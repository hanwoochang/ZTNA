# 2026년 10월 3일 작업 요약

## 1. ZTNA 정책 서버 (Policy Server) 기능 고도화 및 리팩토링
- **위험도 산출(CARTA) 로직 완벽 구현**: 요구사항 명세표를 기준으로, 로그인 및 기기 접속 시 다음과 같은 동적 위험도 산출 로직을 완벽하게 적용했습니다.
  - OS 루팅/탈옥: 즉시 차단 (앱/서버 양방향 방어)
  - 신뢰할 수 없는 기기 (블랙리스트): +100 (사실상 차단 및 세션 강제 종료)
  - 미등록 신규 기기: +30 및 승인 대기(OTP 2차 인증 필수)
  - 불가능한 물리적 이동 속도 (1,000km/h 초과): +70
  - 비정상적 고속 이동 패턴 (500~1,000km/h): +30
  - 장/중거리 이동: +10 ~ +20
  - 새로운 IP 접속, GPS 정보 강제 거부 상태: 각각 +20, +15
  - 비정상 활동 시간대 (새벽 2~5시) 및 업무 외 시간대: +15
- **백엔드 구조 리팩토링**: `routes/auth.js`에 밀집되어 있던 거대한 위험도 산출 로직을 `services/riskEngine.js`로 완전히 분리해내어 코드 가독성과 유지보수성을 극대화했습니다.

## 2. 관리자 웹 (Admin Web) 사용성 및 디자인 개선
- **기능 제외 협의 반영**: 6주차 주제로 배정된 '실시간 접속 위치(Map)' 기능 및 대시보드 컴포넌트를 미리 제거하고, 백엔드의 위치 계산 로직(Haversine)만 유지하기로 협의했습니다.
- **접속 로그 대시보드 UI 고도화**:
  - 기존 4등분(25%) 비율을 `20% / 20% / 40% / 20%` 비율로 수정하여 텍스트가 긴 '사유(Reason)' 컬럼의 시인성을 높였습니다.
  - 사유 텍스트가 여러 줄로 깨지는 현상을 방지하기 위해 말줄임표(Truncate, `...`) 처리를 하고, 마우스 오버 시 전체 사유를 볼 수 있는 툴팁(Tooltip) 기능을 추가했습니다.
- **사이드바 폰트 및 디자인 확장 (CSS 커스텀)**:
  - Tailwind CSS의 기본 사이즈 한계를 돌파하기 위해 인라인 CSS로 강제 적용했습니다.
  - 최적의 균형(골디락스 존)을 찾아 사이드바 너비를 300px로 조정하고, ZTNA Admin 타이틀은 32px(Weight 800), 메뉴 아이콘 및 글씨는 22px 크기로 훨씬 시원시원하고 직관적으로 개편했습니다.

## 3. 모바일 앱 (Client) 버그 수정 및 안정화
- **빨간 방패(차단) 화면 중앙 정렬 버그 패치**: 기존 `View`에 하드코딩된 패딩을 주던 방식을 제거하고, `react-native-safe-area-context`의 `<SafeAreaView>`를 도입해 모든 기종에서 예외 없이 화면 정중앙에 경고 아이콘과 메시지가 정렬되도록 수정했습니다.
- **상태 관리(State) 누락 버그 패치**:
  - `useAuth.ts` 파일에서 `isBlockedByGateway` 상태 변수 선언 누락으로 인해 발생했던 컴파일 에러를 수정했습니다.
  - React Native의 버튼 `onPress` 이벤트 객체가 `isRevoked` 파라미터로 넘어와 논리 구조를 꼬이게 만들던 잠재적 버그를 엄격한 타입/값 검사(`isRevoked === true`)로 완벽히 방어했습니다.
- **로그 및 렌더링 최적화**: 콘솔에 불필요하게 스팸성으로 찍히던 디버그 로그들을 제거하여 최적화했습니다.
