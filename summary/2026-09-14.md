# ZTNA Project Development Summary (2026-09-14)

오늘 진행된 ZTNA(Zero Trust Network Access) 모바일 애플리케이션 프론트엔드 및 백엔드 주요 개발 내역을 요약합니다.

## 1. UI/UX 및 편의성 개선 (Mobbin Design)
- **SVG 아이콘 전면 도입:** 기존 텍스트 이모지를 제거하고, 깔끔한 모노톤의 SVG 아이콘(Mobbin 스타일)을 적용하여 디자인 완성도를 높였습니다.
- **자동 로그인 활성화:** 사용자의 요청에 따라 자동 로그인 기능을 다시 활성화했습니다.
- **키보드 가림 현상 수정:** 안드로이드 환경에서 로그인 시 키패드가 입력창을 가리는 현상을 `KeyboardAvoidingView`와 레이아웃 구조 개선으로 해결했습니다.
- **보안 IP 수집 대기 처리:** 기기 정보(IP 등)를 수집하는 동안에는 로그인을 차단하고 알림을 띄우는 보안 밸리데이션을 추가했습니다.

## 2. 기밀 게시판(Notice Board) 고도화 및 DB 연동
- **스와이프 삭제(Swipe-to-Delete):** `react-native-gesture-handler`를 도입하여, 게시물을 옆으로 밀면 삭제 버튼(휴지통)이 나타나는 모바일 친화적인 UX를 구현했습니다.
- **게시글 수정 기능:** 본인이 작성했거나 관리자(보안팀, 인사팀)인 경우에만 게시물 상세 보기 모달 우측 상단에 '수정' 아이콘이 나타나도록 권한(Permission) 기반 UI를 추가했습니다.
- **MySQL 데이터베이스 영구 연동:** 
  - 백엔드(`target.js`)에서 게시물을 메모리 배열이 아닌 **MySQL DB(`notices` 테이블)**에 저장하도록 전면 개편했습니다.
  - SQL 인젝션 해킹을 방어하기 위해 모든 쿼리에 파라미터화된 쿼리(Parameterized Query)를 적용하여 보안성을 극대화했습니다.

## 3. 사내 일정(Schedule) 캘린더 기능 신설 및 DB 연동
- **캘린더 탭 추가:** 하단 네비게이션에 `Schedule` 탭을 추가하고, `react-native-calendars` 라이브러리를 사용해 달력 UI를 구현했습니다.
- **디자인 커스터마이징:** 달력 크기를 넓히고, 모서리를 둥글게(24px) 처리했으며, 영문 월 표기를 직관적인 숫자(예: '2026년 09월')로 변경했습니다.
- **인라인(Inline) 일정 관리 기능:** 
  - 팝업창(모달) 대신, **달력 날짜를 터치하면 하단 빈 공간에 해당 날짜의 일정이 부드럽게 나타나는 방식**으로 UI를 변경했습니다.
  - 날짜별 일정을 자유롭게 추가하고 삭제할 수 있으며, 일정이 등록된 날짜에는 달력에 푸른색 점(Dot)이 표시되도록 상호작용을 구현했습니다.
- **캘린더 MySQL 연동:** 게시판과 동일하게 일정도 DB(`events` 테이블)에 실시간으로 연동되어 영구 보존되도록 백엔드(`target.js`) API를 구축했습니다.

## 4. 권한 기반 접근 제어(RBAC) 및 보안 논리 고도화
- **작성자 소유권(Ownership) 검증 로직 추가:** 
  - 게시물과 캘린더 일정을 삭제(DELETE)/수정(PUT)할 때, 백엔드에서 현재 사용자(`currentUser`)와 작성자(`author`)를 비교하여 일치하지 않으면 403 Forbidden 에러로 원천 차단했습니다.
  - 프론트엔드에서도 남이 쓴 글이나 일정에는 아예 '휴지통'이나 '스와이프 삭제'가 보이지 않도록 UI 렌더링을 통제했습니다.
- **DB 스키마 정규화 (무결성 강화):** 게시글 수정 시 날짜 필드에 문자열을 갖다 붙이던 임시 방편을 폐기하고, `is_edited`라는 boolean형 전용 컬럼을 DB에 추가(Migration)하여 데이터 정규화를 완벽히 수행했습니다.

## 5. 엔터프라이즈 모바일 보안 기능 (App Security) 추가
- **화면 캡처 원천 차단:** `expo-screen-capture`를 도입해 기밀망(`IntranetScreen`) 진입 시 모바일 OS 레벨에서 화면 캡처 및 녹화가 불가능하도록 방지했습니다.
- **생체 인증(Biometrics) 도입:** 
  - `expo-local-authentication` 모듈을 연동하여, ZTNA 2차 인증(Step-Up) 단계에서 귀찮은 이메일 OTP 대신 FaceID 및 지문 인식을 사용할 수 있게 되었습니다.
  - Settings 화면에 라디오 버튼을 신설해 사용자가 인증 수단(OTP vs Bio) 및 테마를 자유롭게 선택할 수 있으며, `AsyncStorage`를 통해 기기에 영구 저장되도록 구현했습니다.
  - 정책 서버에 생체 인증 전용 검증 API(`/api/verify-bio`)를 신규 개설했습니다.
